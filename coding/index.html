Technical Art

I have developed many custom scripts and plugins to standardize and automate pipelines for high-volume production of 3D models, leveraging APIs from software such as Blender and Substance Painter. These tools ensure project consistency for different artists and teams while significantly reducing repetitive manual work.

  • Workflow Standardization
    Creating scripts and plugins to enforce naming conventions, file formats, and complex folder hierarchies across large-scale projects.
  • Environmental Synchronization
    Automating lighting and camera configurations to maintain visual parity between different 3D software suites.
  • Geometry & Shading Logic
    Scripting automated mesh generation, processing, and analysis alongside dynamic setups for materials/shaders.
  • High-Volume Asset Management
    Implementing bulk import & export systems for 3D authoring software to streamline asset production and deployment.

Systems Integration

I have designed and deployed multiple integration layers between Enterprise Systems (ERP/CRM) and cloud-based web services to synchronize B2C and B2B data across teams, departments and companies.

  • Manufacturing and Mesh Processing Automation
    Developing scripts that bridge cloud-based storage, mesh processing, and the factory floor, automating the retrieval and preparation of 3D assets while interfacing with specialized industrial CNC machines and 3D printers to enable production based on real-time scheduling.
  • Healthcare Data Management
    Connecting Redmine and AWS to manage the secure retrieval, storage and delivery of confidential patient information, including 3D medical images, with the implementation of diverse features such as anonymization.
  • Production Lifecycle
    Integrating Odoo with Google Cloud to automate the flow of CAD and manufacturing data from initial design to the factory floor and warehouse management, up to sales and marketing.
  • Cloud Operations & Monitoring
    Developing interfaces between Google Cloud, AWS and Discord to enable real-time system notifications, remote document control, automated translations, and more.

XR Research & Development

I have prototyped a couple of simple cross-platform VR/AR applications using Unity and Unreal Engine for Meta Quest and Pico ecosystems. These projects focused on bridging cloud-based asset repositories with real-time visualization for XR headsets.

  • Goals
    The apps allowed the user to select from a list of 3D models, and it would dynamically fetch the 3D model from a remote server into the XR environments, adding physics and allowing the user to manipulate the asset in space.
  • Challenges
    Biggest challenges in both cases were accessing Google Cloud from the Meta and Pico ecosystems and creating good shadow-casting solutions in AR.

While these remain small personal R&D initiatives, they provided critical insights into the infrastructure required for cloud-connected spatial computing.


Machine Learning & AI

While over-reliance in AI risks creative stagnation and job obsolescence, strategic integration can act as an enabler and enhancer for artists and developers across all fields. My personal experience with ML/AI includes:

  • Mesh Processing & Medical Imaging
    My first hands-on contact with AI was in 2016, as I was designing algorithms for 3D Medical Imaging (CT/3D scans). I developed multiple mesh processing and mesh analysis tools, including the use of Machine Learning for automated segmentation and classification of medical 3D models.
  • General Software Development
    As LLMs evolved with real-time web access, AI became significantly more reliable to access technical information from fragmented API documentations, forums and blog posts. I generally utilize LLMs to rapidly prototype ad-hoc algorithms, to facilitate debugging processes, and to assist in documentation research for more complex implementations.
  • 3D Texturing and PBR Materials
    The development of AI for image processing matured significantly earlier than LLMs, allowing me to integrate AI-driven image upscaling for reference photos many years ago. More recently, popular 3D authoring software such as Substance 3D Sampler are increasingly adding AI tools, facilitating tasks such as estimating PBR material parameters based on reference photos.
  • 3D Model Generation
    While the industry is currently flooded with generative 3D solutions, I maintain a critical eye on output quality. In my experience, these automated products currently fail to meet professional topology standards and lack the non-destructive editability required for production-ready assets.
