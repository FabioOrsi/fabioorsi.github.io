Technical Art

I have developed many custom algorithms to automate complex and repetitive processes within high-volume production of 3D assets, leveraging APIs from software such as Blender and Substance Painter.

Either via standalone scripts or fully integrated plugins, addons and extensions, these tools ensure quality and technical consistency across diverse artists and teams, while also significantly reducing manual tasks.

  • Geometry & Shading Logic
    Developing algorithms for automated mesh generation, mesh processing, and mesh analysis alongside automated setups for textures and materials/shaders.
  • High-Volume Asset Management
    Implementing bulk optimization and import/export solutions for 3D authoring software to streamline asset production, management and deployment.
  • Workflow Standardization
    Creating scripts and plugins to enforce naming conventions, file formats, and complex folder hierarchies across large-scale projects.
  • Environmental Synchronization
    Automating lighting and camera configurations to maintain visual parity between different 3D authoring software, web viewers and game engines.

Systems Integration

I have designed and deployed multiple integration layers between Enterprise Systems (ERP/CRM) and cloud-based web services to synchronize B2C and B2B data across teams, departments and companies. Some of the platforms include Redmine, Odoo, AWS (EC2 and S3), Google Cloud (Firebase and Google Sheets) and Discord.

  • Manufacturing and Mesh Processing Automation
    Integrating pipelines for in-demand manufacturing using CNCs and 3D printing, automating database management, mesh processing, scheduling, and real-time control of machines.
  • Healthcare Data Management
    Bridging B2B platforms to manage the secure retrieval, storage and delivery of confidential patient information, including 3D medical images, with features such as anonymization.
  • Production Lifecycle
    Connecting ERP/CRMs with cloud services to facilitate the flow of real-time production data, integrating design and engineering teams, factory floor, warehouse, sales, up to marketing.
  • Cloud Operations & Monitoring
    Developing interfaces between ERPs, cloud services, messaging apps, and custom hardware to enable real-time system notifications, remote document control, translations, and more.

XR Research & Development

I have prototyped a couple of simple cross-platform VR/AR applications using Unity and Unreal Engine for Meta Quest and Pico ecosystems. These projects focused on bridging cloud-based asset repositories with real-time visualization for XR headsets.

  • Goals
    The apps allowed the user to select from a list of 3D models, and it would dynamically fetch the 3D model from a remote server into the XR environments, adding physics and allowing the user to manipulate the asset in space.
  • Challenges
    Biggest challenges in both cases were accessing Google Cloud from the Meta and Pico ecosystems and creating good shadow-casting solutions in AR.

While these remain small personal R&D initiatives, they provided critical insights into the infrastructure required for cloud-connected spatial computing.


Machine Learning & AI

While over-reliance in AI risks creative stagnation and job obsolescence, strategic integration can act as an enabler and enhancer for artists and developers across all fields. My personal experience with ML/AI includes:

  • Mesh Processing & Medical Imaging
    Developing multiple 3D mesh processing and analysis tools for the medical field, including the use of Machine Learning for automated segmentation and classification of CT/3D scans.
  • General Software Development
    Utilizing LLMs to rapidly prototype simple ad-hoc algorithms, to facilitate debugging processes, and to assist in API documentation research for more complex implementations.
  • 3D Texturing and PBR Materials
    Integrating AI image upscaling for reference photos of products and materials. Using AI tools from apps such as Substance 3D Sampler to estimate the parameters of PBR materials.
  • 3D Model Generation *
    Experimenting with generative AI for 3D, however it is noticeable that these solutions still lack professional topology standards and editability required for most production assets.
